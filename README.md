# chess.skay

**Очень ахуенные шахматы** — автономный десктопный клиент для Linux в формате AppImage.

Автор: **skayinray** — <https://github.com/skayinray>

## Возможности

- **Полные правила шахмат**: рокировка, взятие на проходе, превращение,
  мат, пат, insufficient material, правила 50/75 ходов и троекратное повторение.
- **Собственный движок** на Python: минимакс с alpha-beta, таблица
  перестановок, оценка по material + piece-square tables, итеративное
  углубление. Четыре уровня: новичок, клубный игрок, мастер, гроссмейстер.
  Никаких внешних программ (Stockfish и т.п.) не требуется.
- **Главное меню**: игра с компьютером, игра вдвоём, продолжение партии,
  смена темы и «О программе» — сразу при запуске.
- **Фигуры chess.com**: оригинальный набор neo с прозрачным фоном (плюс
  классический набор cburnett на выбор в меню «Вид → Стиль фигур»).
- **Красивая доска**: подсветка последнего хода, шаха, выбранной клетки и
  доступных ходов. По умолчанию зелёная доска в стиле chess.com, ещё четыре
  темы — в меню «Вид → Тема доски». Ходы можно делать кликом или перетаскиванием.
- **Интерфейс**: крупный читаемый текст, вертикальная полоса оценки рядом с
  доской, таблица ходов с колонками «Белые/Чёрные», компактная сетка кнопок.
  Шрифты с кириллицей включены в AppImage — текст одинаков на всех системах.
- **Пре-мувы**: во время хода компьютера можно заранее планировать свой ход —
  он выделяется оранжевой рамкой и стрелкой, применяется сразу после ответа
  соперника. Правый клик снимает запланированный ход.
- **Анимации**: фигуры плавно переезжают между клетками (320 мс, `InOutCubic`,
  лёгкая дуга), взятые фигуры растворяются, последний ход пульсирует. Движок
  отдаёт GIL и включается только после окончания анимации, поэтому она не
  дёргается.
- **Рейтинг Эло**: очки начисляются/списываются после каждой партии по формуле
  Эло (K=32), сохраняются между запусками и показываются в меню и на карточках
  игроков. Сложность компьютера задаёт его рейтинг.
- **Подсказка**: стрелкой показывается лучший ход (поиск уровня «мастер»).
- **Часы**: произвольный контроль времени с прибавкой; таймеры белых и чёрных,
  подсветка цейтнота.
- **Партия**: список ходов в нотации SAN, отмена/повтор, сдача,
  автоматическое сохранение последней партии, экспорт/импорт PGN.
- **Разное**: переворот доски, оценочная шкала, захваченные фигуры,
  кликабельная ссылка на автора в меню «Справка».

## Запуск

```bash
chmod +x chess.skay-x86_64.AppImage
./chess.skay-x86_64.AppImage
```

AppImage не требует установки: внутри уже есть Python, PySide6, Qt,
python-chess и оба набора фигур.

## Сборка

```bash
python3 -m pip install -r requirements.txt
./build_appimage.sh /path/to/appimagetool.AppImage
```

## Структура

```
src/
  main.py              точка входа
  chess_app.py         главное окно, логика партии, часы, AI-поток
  board_widget.py      отрисовка доски и фигур, ввод
  engine.py            поиск и оценка
  dialogs.py           новая партия, превращение, о программе
  resources/           иконка, шрифт, AppStream
tools/
  build_appimage.py    сборщик AppImage
  make_icon.py         генератор иконки
```
